# 주식회사 엔투씨 홈페이지 (n2c.co.kr)

정적 홈페이지입니다. 빌드 과정 없이 파일 그대로 Vercel에 배포됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 홈페이지 전체 (회사소개, 사업분야, 회사정보, 전자공고) |
| `notices.js` | 전자공고 목록 — **공고를 올릴 때는 이 파일만 수정** |
| `favicon.svg` | 브라우저 탭 아이콘 |
| `files/` | (필요 시) 공고 첨부 PDF를 넣는 폴더 |

## 전자공고 올리는 방법

1. GitHub에서 `notices.js`를 열고 연필(Edit) 아이콘을 누릅니다.
2. `window.NOTICES = [` 바로 아래에 파일 상단 예시처럼 항목을 하나 추가합니다.
3. [Commit changes]를 누르면 Vercel이 1~2분 안에 자동으로 다시 배포합니다.
4. 첨부 PDF가 있으면 `files/` 폴더에 업로드하고 `file: "files/파일명.pdf"`로 적습니다.

공고 하나를 바로 가리키는 주소: `https://n2c.co.kr/#n-공고id`
